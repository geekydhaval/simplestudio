# CLAUDE.md

Guidance for Claude Code when working in this repo.

## What this is
Simple Studio's landing page. Vanilla JS + Vite, GSAP/ScrollTrigger, Lenis, Canvas 2D. No framework. Keep it that way unless asked.
Visual language: a three-column grid with dashed guides and "+" rule markers, extra-black extended uppercase headlines (second lines dimmed), light skeuomorphic cards, pressable dark buttons with dot-matrix icons, Geist Mono chips.

## Commands
- `npm run dev` — dev server on :5173
- `npm run build` — static build to `dist/`

## Where things live
- Content: `src/data.js` (edit copy here, not in `main.js`). `featured` = selected work tiles (the main event), `work` = the lab.
- Static copy and section structure: `index.html`. Sections are filled by JS through `data-*` hooks (`data-featured`, `data-steps`, `data-benefits`...).
- Logo marks are generated by `markSvg()` in `src/main.js` and injected into `[data-mark="nav|dot|badge|glyph|orb|team"]`; dot-matrix icons into `[data-dots="arrow|grid|star|quote|flask|check|pause|seven|code"]`.
- Motion/interaction: `src/main.js`. Line field behind the logo object: `src/lines.js`. Generated covers/avatars: `src/art.js`.
- Tokens and styles: `src/styles.css` (`:root` holds palette, fonts, frame width).

## Media
- 3D renders, craft-fan images and lab covers are served from the Webflow CDN (`cdn` in `src/data.js`), not copied into the repo. If the Webflow site's assets are ever deleted, download them into `public/work/` and point the data at the local paths.
- App screens from Figma live in `public/work/` (`hda-*.webp`, `scallop-home.webp`).
- Service videos play only while on screen (IntersectionObserver) and speed up on hover.

## Crafts (under the hero)
- Four glow icons (App, Website, Brand, Motion) from `crafts` in `src/data.js`, drawn in code by `glowIcon()` in `main.js`: dark glass tile, white SVG glyph fading into the craft colour, a bottom glow in `--glow` (set per `.craft__item--{id}`), and a red badge with the number of pieces. Each holds a stack of work that peeks out from behind it and fans out in an arc on hover/focus (CSS transitions driven by `.is-open`; positions are `--x/--y/--r` set in `main.js`). On touch screens a tap opens the work in a horizontal tray under the icons. On desktop the four open once in turn when the section first comes into view, until the visitor hovers.
- Motion cards are 3D render videos that only play while their craft is open.

## Design rules (keep these)
- Background `#0f0f0f` with a faint 44px grid. Lime `#DBF130` is the signal colour (CTAs, the hero badge, ticket band, highlights). Violet, magenta and blue are accents (chips, bars, dots).
- Fonts: Archivo Variable at `wdth` 125 / weight 900 for display (uppercase), Sofia Pro (fallback Outfit Variable) for body, Geist Mono Variable for chips and labels.
- Section titles: icon square + coloured bar + uppercase title (`.bar-title`).
- Never invent testimonials, client logos or metrics.
- Always respect `prefers-reduced-motion`. Test at 390px wide; no horizontal page scroll (grids use `minmax(0, 1fr)`; long display words must fit).

## Brand
- Logo = a ring (heavier at the bottom, viewBox 0 0 511 445) with two swooshes crossing it; the inner disc is cut out with a mask so the background shows through. Paths live in `LOGO` in `src/main.js`; `markSvg({ color, accent, opacity })` draws it. Standalone files: `public/logo-mark.svg`, `public/favicon.svg`.
- Name: "Simple Studio" (lockup "Simple / Studio"). Never "Simple Design".

## Gotchas
- Don't put CSS `transition` on `transform` for elements GSAP animates. The nav hides with a CSS class (`.is-hidden`) and is never animated by GSAP.
- Reveal targets are set to opacity 0 by GSAP and revealed with `ScrollTrigger.batch`; if you add a section, add its cards to `revealSel`.
- After content changes that affect height, call `ScrollTrigger.refresh()` (already done on font load, window load, FAQ toggle and plan switch).
- The scallopx tile scrolls its tall screenshot on hover using `--scroll`, computed after the image loads.
- `--a` is a registered `@property` (angle) used by the glow card. Never reuse `--a` for anything else; the HDA fan uses `--i` / `--ia`.
- `[data-tilt]` cards are tilted by GSAP on pointer move; don't add CSS transform transitions to those elements.

## Social preview
- `public/og.png` (1200×630) is rendered from `og/og.html` with Playwright: `python3 og/render.py`. Alternatives live in `og/og-b.html` and `og/og-c.html` (previews in `og/variants/`); render one with `python3 og/render.py og-b public/og.png` to make it the live image.
